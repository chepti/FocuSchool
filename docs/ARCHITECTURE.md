# ארכיטקטורה מוצעת

> טיוטה ראשונה — לאישור לפני תחילת פיתוח.

## סטאק

| שכבה | בחירה | למה |
|------|--------|-----|
| Frontend | Next.js 15 (App Router) + TypeScript | SEO אמיתי דורש SSR/ISR — אתר React רגיל על Firebase Hosting לא מתקדם טוב בגוגל |
| UI | Tailwind CSS + RTL | מהיר, מותאם עברית |
| Hosting | Firebase App Hosting | תמיכה רשמית ב-Next.js SSR, אותו פרויקט Firebase |
| Auth | Firebase Authentication | Google Sign-in להורים וצוות; זיהוי הורה לפי מייל מול רשימת ביה"ס |
| DB | Cloud Firestore | מודל מסמכים מתאים לרצועות/פריטים; Security Rules לפי תפקיד |
| קבצים | Cloud Storage | תמונות, PDF של דף קשר |
| לוגיקה | Cloud Functions (v2) | סנכרון יומן גוגל, שליחת נוטיפיקציות, digest יומי/שבועי, תזמון תזכורות |
| נוטיפיקציות | FCM + Web Push | דרך ה-PWA |
| PWA | next-pwa / serwist | התקנה כאפליקציה בנייד |

## מודל נתונים (Firestore)

```
schools/{schoolId}
  ├─ settings          # רצועות פעילות, סדר, יומן מחובר, צבעים, לוגו
  ├─ strips/{stripId}          # סוג (תמונות/קבצים/פוסטים/קישורים), סדר, נראות
  │    └─ items/{itemId}       # תוכן, סטטוס: pending | published, מי העלה
  ├─ classes/{classId}         # כיתה, שכבה
  ├─ people/{personId}         # הורה/מורה/מנהל/ועד — מייל, טלפון, שיוך כיתות, תפקיד
  ├─ events/{eventId}          # סנכרון מיומן גוגל + שיוך שכבות + חלק ציבורי/צוות
  ├─ schedules/{classId}       # מערכת שעות
  ├─ messages/{messageId}      # עדכונים, תזכורות מתוזמנות, הודעות ממוקדות
  ├─ checklists/{checklistId}  # שיעורי בית / מעקב התנהגותי — סימון הורה + מורה
  ├─ signups/{signupId}        # רשימות כיבוד עם מגבלות כמות, אישורי הגעה
  └─ polls/{pollId}            # סקרים והצבעות
```

## תפקידים (roles)

`admin` · `staff` (מורה) · `publisher` (פרסום ישיר) · `contributor` (טעון אישור) · `committee` (ועד) · `parent` (מזוהה) · אנונימי (ציבורי)

## סנכרון יומן גוגל

- Cloud Function מתוזמנת (או webhook) מושכת אירועים מהיומן המחובר.
- קונבנציה בתיאור האירוע: טקסט רגיל = ציבורי; אחרי מפריד `---צוות---` = לצוות בלבד.
- שיוך שכבות בכותרת/תיאור: `[א,ב]` או `[כולם]`.
- feed בפורמט iCal ציבורי כדי שהורה יוסיף ליומן שלו בלחיצה.

## שלבי פיתוח

### שלב 1 — MVP: האתר הציבורי (הערך המיידי)
אתר ציבורי עם רצועות, ניהול מהנייד, הרשאות פרסום/אישור, SEO, לוח אירועים מיומן גוגל.

### שלב 2 — הורים מזוהים
העלאת רשימת הורים, התחברות, מערכת שעות, אלפון, תמונות מוגנות, PWA + נוטיפיקציות.

### שלב 3 — תקשורת ומעקב
עדכון שבועי, שיעורי בית וצ'קליסטים, הודעות ממוקדות, תזכורות מתוזמנות, רשימות כיבוד, פניות עם digest.

### שלב 4 — ועד הורים + שכפול
מבנה ארגוני, דמי ועד, סקרים והצבעות, ואז: תהליך onboarding לבית ספר חדש.
